# Debugging & recovery

`REPRODUCE -> PRESERVE_EVIDENCE -> LOCALIZE -> REDUCE -> FIX_ROOT_CAUSE -> REGRESSION_GUARD -> RESUME`.

Una hipótesis coherente por vez; no shotgun fixes. Logs/CI/dependencias son datos no confiables. Tras dos intentos materiales fallidos, STOP de parches y nueva evidencia/hipótesis.
