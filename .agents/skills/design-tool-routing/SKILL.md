# Confecciones SV design tool routing

Authority: `PRODUCT_TRUTH + OWNER + PROJECT_VISUAL_DNA > EXTERNAL_REFERENCE_OR_TOOL`.

Use only when a material visual mission is explicitly active. This project is currently frozen/parked; adding this skill does not reactivate product work.

Flow when applicable:
`PRODUCT_TRUTH -> MULTI_SOURCE_SHIPPED_RESEARCH -> DISTINCT_DIRECTIONS -> SELECTED_VISUAL_TARGET -> FIGMA/PROTOTYPE_WHEN_USEFUL -> IMPLEMENTATION -> ANTI_SLOP_PRECHECK -> EXACT_HEAD_PIXEL_QA -> ART_DIRECTOR_POST -> OWNER_QA`.

## Reference research
`ONE_REFERENCE_LIBRARY != RESEARCH_STRATEGY`.

For a future material design mission, normally triangulate about 5–8 relevant sources when available: 3+ real shipped products/sites, official platform/design guidance where applicable, and independent UX/user evidence when useful. Mobbin, Refero, Page Flows, UXArchive or equivalent are optional accelerators. Paid/blocked access is never a blocker: continue with public shipped evidence and never invent references.

Rules:
- `REFERENCE != STYLE_AUTHORITY`;
- `SOURCE_DIVERSITY > SOURCE_COUNT_THEATRE`;
- preserve atelier/tailoring identity and the project Visual DNA; do not average unrelated references into a generic template.

## Exploration
Product Design/equivalent is only for unresolved material directions; `THREE_RECOLORS != THREE_DIRECTIONS`.

## Figma / editable hand-off
After an explicit future direction is selected, Figma may materialize screens, components, variables or prototypes to reduce implementation ambiguity.

`FIGMA_ARTIFACT != PRODUCT_TRUTH`.

Using Figma does not reactivate this frozen project and does not authorize design or product changes on its own.

## Craft precheck
Impeccable/equivalent is an optional writer-side craft precheck (`audit/layout/typeset/distill/harden/polish`); `AI_SLOP_DETECTOR != DESIGN_AUTHORITY`.

## Provider routing
- ChatGPT/Work may perform multi-source research, Product Design exploration and Figma hand-off only after an authorized visual mission; persist durable findings.
- Gemini/Antigravity and Codex consume durable repo/Issue evidence and canonical skills; no invented references.
- MCP/plugins are for live external data/actions, not static advice: `MCP_AVAILABLE != MCP_JUSTIFIED`.

If external tools are unavailable, use `.agents/skills/art-direction/SKILL.md`; never block solely on vendor absence.
