# Motion design

`MOTION_WITHOUT_PURPOSE = NOISE` · `MOTION_DIRECTION != ANIMATION_LIBRARY` · `CHEAPEST_CAPABLE_ANIMATION_PRIMITIVE_FIRST` · `REDUCED_MOTION_IS_PRODUCT_STATE`.

CSS -> WAAPI/View Transitions -> Motion -> GSAP -> Lottie lineal -> Rive interactivo -> 3D solo si lo requiere. Remotion = vídeo renderizado, no microinteracción normal. Probar interruption/touch/reduced-motion; motion nunca único portador de estado.
